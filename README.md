# hello-world-practice

A tiny practice repo for learning the pull request workflow with Claude Code.

## What is this?

This repo exists so you can see, end to end, how a change goes from an idea to a merged pull request on GitHub.

## Getting Started

1. Clone the repo: `git clone https://github.com/feez1110/hello-world-practice.git`
2. Create a branch for your change: `git checkout -b my-change`
3. Make your edit, then commit it: `git commit -am "Describe your change"`
4. Push the branch: `git push origin my-change`
5. Open a pull request on GitHub and merge it once you're happy
